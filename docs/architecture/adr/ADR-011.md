# ADR-011: Editions via extensions; Commercial purity enforced by build

| Date | Status |
|---|---|
| 2026-11-04 | Proposed ⚑ |

## Context
Jakojast/lodging concepts in 106 files and 66 PHP files (hosts, properties, settlements, site sync, prompts, seeds).

## Problem
Generic Commercial Edition without Jakojast coupling (§12.2) while keeping Jakojast features.

## Options considered
A) Fork. B) Feature flags in core. C) Core + `extensions/jakojast` with manifest hooks; build excludes it and scans for vocabulary.

## Decision
C. Inventory of what moves is produced in M9 from the 106-file list.

## Consequences
Jakojast edition = core + extension; Commercial = core.

## Security impact
Extension hooks go through the same permission and event APIs.

## Performance impact
None measurable.

## Migration impact
Moving tables to extension ownership does not move data (same DB).

## Rollback considerations
Extension can be re-inlined if needed.
