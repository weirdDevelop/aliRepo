# ADR-013: Instagram: YarAPI as primary provider; others frozen

| Date | Status |
|---|---|
| 2026-11-04 | Proposed ⚑ |

## Context
Four Instagram adapters (YarAPI, RoboClick, Directsaz, Graph). YarAPI's Oct 2026 guide positions it as the single public API; its adapter matches the guide; RoboClick's doc is incomplete; no docs for Directsaz/Graph.

## Problem
Reduce maintenance and undocumented-behaviour risk (§7.1 'never invent endpoints').

## Options considered
A) Keep all four equal. B) YarAPI primary, RoboClick supported, Directsaz/Graph frozen. C) YarAPI only.

## Decision
B, pending owner confirmation of business relationships.

## Consequences
New Instagram features built for YarAPI first; RoboClick-only operations marked unverified.

## Security impact
Fewer credential types to protect.

## Performance impact
—

## Migration impact
Existing accounts keep their provider until moved.

## Rollback considerations
Unfreeze an adapter if a customer needs it.
