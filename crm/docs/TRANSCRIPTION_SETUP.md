# راهنمای نصب تبدیل صدا به متن

این قابلیت سه روش پشتیبانی می‌کند که از تنظیمات (بخش «🎙 تبدیل صدا به
متن مکالمات») قابل انتخاب است:

| روش | هزینه | کیفیت | کجا اجرا می‌شود |
|---|---|---|---|
| **local** | رایگان | متوسط | روی سرور خودتان (b7s/whisper-php) |
| **groq** ⭐ پیشنهادی | ~$۰.۰۴ در ساعت صدا | بالا (Whisper large-v3) | سرویس ابری Groq |
| **openai** | ~$۰.۳۶ در ساعت صدا (۹ برابر گروک) | بالا (مشابه Groq) | سرویس ابری OpenAI |

**توصیه:** اگر بودجه‌ی کوچک API قابل قبول است، **Groq** بهترین ترکیب
کیفیت/قیمت را دارد (همان مدل بزرگ Whisper، فقط چند دلار در ماه برای
حجم متوسط تماس‌های یک کسب‌وکار). کلید API را از
[console.groq.com](https://console.groq.com) بگیرید و در تنظیمات وارد کنید — نیازی به نصب چیزی روی سرور نیست، همین کافی است.

⚠️ **نکته‌ی حریم خصوصی:** در روش‌های ابری (groq/openai)، فایل صوتی
مکالمه به سرور خارجی ارسال می‌شود. روش local هیچ داده‌ای را از سرور
شما خارج نمی‌کند.

---

## گزینه‌ی محلی (Local - رایگان، بدون هزینه‌ی مستمر)

این قابلیت با کتابخانه‌ی [`b7s/whisper-php`](https://github.com/b7s/whisper-php)
پیاده‌سازی شده که موتور Whisper.cpp را روی خودِ سرور شما اجرا می‌کند —
هیچ فایل صوتی به هیچ سرویس خارجی ارسال نمی‌شود.

## پیش‌نیاز نصب گزینه‌ی محلی (Local - رایگان)
- SSH و دسترسی root/sudo (برای نصب ابزار کامپایلر)
- PHP ≥ 8.2
- حداقل ۴ هسته CPU و ۸ گیگ RAM (برای مدل `medium` که برای فارسی توصیه می‌شود)

## مراحل نصب (یک‌بار، از طریق SSH)

```bash
# ۱) نصب ابزار کامپایلر (Ubuntu/Debian)
sudo apt update
sudo apt install -y git cmake make build-essential

# ۲) رفتن به پوشه‌ی پروژه
cd /path/to/jakojast

# ۳) نصب Composer (اگر از قبل ندارید)
curl -sS https://getcomposer.org/installer | php
php composer.phar install
# یا اگر composer سراسری نصب دارید:
composer install

# ۴) دانلود/کامپایل باینری Whisper + مدل + FFmpeg
php ./vendor/bin/whisper-setup --model=medium
```

این مرحله‌ی آخر ممکن است چند دقیقه طول بکشد (کامپایل از سورس + دانلود
حدود ۱.۵ گیگابایت مدل).

## بعد از نصب

۱. در تنظیمات جاکجاست → «🛠 به‌روزرسانی جداول دیتابیس» را بزنید (ستون‌های
   `transcript`, `transcript_status`, `transcribed_at` به جدول `calls`
   اضافه می‌شوند).

۲. برای استخراج متن **تک‌تک و دستی**: در صفحه‌ی جزئیات هر تماسِ ضبط‌شده،
   دکمه‌ی «🎙 استخراج متن مکالمه» را بزنید.

۳. برای پردازش **خودکار و دسته‌ای** (پیشنهادی): این خط را به crontab
   سرور اضافه کنید تا هر ۵ دقیقه چند تماس تازه‌ی ضبط‌شده را خودکار
   پردازش کند:

```bash
crontab -e
# این خط را اضافه کنید (مسیر را با مسیر واقعی پروژه‌تان جایگزین کنید):
*/5 * * * * /usr/bin/php /path/to/jakojast/cron/transcribe_calls.php >> /path/to/jakojast/logs/transcribe.log 2>&1
```

## بار روی سرور (خلاصه)

با مدل `medium` و سرور ۴-۸ هسته / ۸-۱۶ گیگ رم: هر ۱ دقیقه مکالمه حدود
۴۵-۶۰ ثانیه CPU لازم دارد. برای حجم متوسط تماس‌های روزانه‌ی یک کسب‌وکار
(چند صد تماس در روز)، این پردازش کاملاً در پس‌زمینه (توسط cron) جذب
می‌شود و تأثیری روی سرعت CRM برای کاربران ندارد.

## عیب‌یابی

- اگر دکمه‌ی «استخراج متن» پیام «سرویس نصب نشده» داد → یعنی مرحله‌ی ۴
  بالا (`whisper-setup`) کامل انجام نشده یا composer autoload لود
  نمی‌شود؛ چک کنید فایل `vendor/autoload.php` در ریشه‌ی پروژه وجود دارد.
- اگر استخراج متن با خطا شکست خورد → لاگ سرور (`core/Logger`) را چک
  کنید؛ پیام خطای دقیق کتابخانه‌ی Whisper معمولاً علت را مشخص می‌کند
  (مثلاً کمبود حافظه، یا مدل هنوز دانلود نشده).
- نام دقیق متد تنظیم زبان فارسی ممکن است بین نسخه‌های این کتابخانه فرق
  داشته باشد؛ منطق مربوطه در `api_integration/TranscriptionService.php`
  متد `callWhisperLibrary()` جدا شده تا در صورت نیاز به تنظیم دقیق، فقط
  همان یک متد نیاز به اصلاح داشته باشد.

## ⚠️ باگ رفع‌شده: نتایج کاملاً نامرتبط/بی‌معنی («hallucination»)

اگر متن استخراج‌شده با چند کلمه‌ی درست شروع می‌شود ولی بعد به جملاتی
کاملاً بی‌ربط به مکالمه‌ی واقعی تبدیل می‌شود، علتش تقریباً همیشه این
است: کتابخانه بدون تعیین صریح زبان فارسی اجرا شده و Whisper مجبور شده
زبان را از روی صدای کم‌کیفیت تلفن حدس بزند - که روی صدای مبهم/نویزی
باعث «تولید» متن روان اما کاملاً ساختگی می‌شود.

نام واقعی متد تنظیم زبان در کتابخانه‌ی `b7s/whisper-php`، `fromLanguage()`
است، نه `language()` (که کد قبلی این پروژه اشتباهاً صدا می‌زد). چون این
متد وجود نداشت، تنظیم زبان همیشه بی‌صدا نادیده گرفته می‌شد. رفع شده -
اگر بازهم این الگو دیده شد، پنل «🪵 لاگ خطاهای سرور» در تنظیمات را برای
خط `callLocalWhisperLibrary: تشخیص کلاس/متد` چک کنید - می‌گوید آیا
`persian_language_set` واقعاً `true` شده یا نه.

**تماس‌هایی که قبلاً با این باگ متن اشتباه گرفته‌اند خودکار اصلاح
نمی‌شوند** - از صفحه‌ی جزئیات هر تماس، دکمه‌ی «🎙 استخراج دوباره» را بزنید.
