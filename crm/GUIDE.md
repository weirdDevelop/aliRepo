## 1. نصب سیستم

### مرحله ۱: اجرای install.php

پس از آپلود فایل‌ها روی هاست، در مرورگر به آدرس زیر بروید:

```
https://your-domain.com/install.php
```

![نصب](screenshots/install.png)

> 📸 **اسکرین‌شات**: فرم نصب جاکجاست با فیلدهای دیتابیس و مدیر

### مرحله ۲: پر کردن فرم

- **میزبان دیتابیس**: `localhost` (یا آدرس سرور DB)
- **نام دیتابیس**: `jakojast` (یا نامی که ساختید)
- **نام کاربری دیتابیس**: یوزر DB
- **رمز عبور دیتابیس**: پسورد DB
- **نام کاربری مدیر**: `admin` (پیش‌فرض)
- **رمز عبور مدیر**: `123` (حتماً تغییر دهید)

### مرحله ۳: پایان نصب

پس از کلیک روی «🚀 شروع نصب»:
- ۲۰ جدول ایجاد می‌شود
- کاربر مدیر با هش bcrypt ذخیره می‌شود
- تنظیمات اولیه درج می‌شود
- فایل `install.php` خودش حذف می‌شود
- فایل `.installed` ایجاد می‌شود (برای جلوگیری از اجرای مجدد)

![نصب موفق](screenshots/install-success.png)

> 📸 **اسکرین‌شات**: پیام نصب موفق با لینک ورود

## 11. چت داخلی

از سایدبار روی **💬 چت داخلی** کلیک کنید:

![چت](screenshots/chat.png)

> 📸 **اسکرین‌شات**: صفحه چت با ۶ کانال + پیام‌های real-time

**ویژگی‌ها**:
- **۶ کانال**: عمومی، مالی، پشتیبانی، فروش، میزبانان، فنی
- **Long Polling real-time**: پیام‌ها فوراً نمایش داده می‌شوند (بدون WebSocket)
- **کاربران آنلاین**: بر اساس آخرین پیام در ۵ دقیقه اخیر
- **آواتار رنگی**: با حروف اول نام
- **پیام‌های خود کاربر**: با استایل متفاوت (راست‌چین، رنگ primary)

**نکات**:
- با Enter پیام ارسال می‌شود
- اگر به تب دیگر بروید، polling متوقف می‌شود (صرفه‌جویی منابع)
- با برگشت به تب، polling از سر گرفته می‌شود
- پیام‌ها با strip_tags پاک‌سازی می‌شوند (XSS prevention)

## 16. تنظیم Cron Job

برای همگام‌سازی خودکار تماس‌ها هر ۵ دقیقه:

### روش ۱: cPanel

۱. وارد cPanel شوید
۲. به **Cron Jobs** بروید
۳. روی **Add New Cron Job** کلیک کنید
۴. تنظیمات:
   - **Common Settings**: `Every 5 minutes`
   - **Command**: 
     ```
     php /home/username/public_html/cron_sync.php
     ```
۵. روی **Add New Cron Job** کلیک کنید

![Cron cPanel](screenshots/cron-cpanel.png)

> 📸 **اسکرین‌شات**: تنظیم Cron Job در cPanel

### روش ۲: crontab (SSH)

```bash
crontab -e
```

خط زیر را اضافه کنید:

```
*/5 * * * * /usr/local/bin/php /home/username/public_html/cron_sync.php
```

ذخیره و خروج.

### روش ۳: wget (اگر PHP CLI نیست)

ابتدا یک `cron_key` در صفحه تنظیمات بسازید (مثلاً `mySecretKey123`)، سپس:

```
*/5 * * * * wget -q -O /dev/null https://your-domain.com/cron_sync.php?key=mySecretKey123
```

### بررسی عملکرد

پس از ۵ دقیقه، فایل `logs/error.log` را بررسی کنید — باید پیام "Cron sync started" و "Cron sync completed" ببینید.

## 17. تنظیم Webhook تلفنچی

برای دریافت رویدادهای real-time تلفنچی:

### مرحله ۱: دریافت URL

URL وب‌هوک شما:
```
https://your-domain.com/webhook.php
```

### مرحله ۲: تنظیم در پنل تلفنچی

۱. وارد پنل تلفنچی شوید
۲. به بخش **Webhooks** یا **تنظیمات رویداد** بروید
۳. URL زیر را وارد کنید:
   ```
   https://your-domain.com/webhook.php
   ```
۴. رویدادهای مورد نظر را انتخاب کنید:
   - ✅ `call_started` (شروع تماس)
   - ✅ `call_answered` (پاسخ به تماس)
   - ✅ `call_ended` (پایان تماس)
5. روی **ذخیره** کلیک کنید

![Webhook تلفنچی](screenshots/telefonchy-webhook.png)

> 📸 **اسکرین‌شات**: تنظیم Webhook در پنل تلفنچی

### مرحله ۳: تست

یک تماس آزمایشی انجام دهید. سپس در phpMyAdmin:

```sql
SELECT * FROM telefonchy_events ORDER BY received_at DESC LIMIT 10;
```

باید رویدادها را ببینید.

### امنیت (اختیاری)

برای جلوگیری از درخواست‌های غیرمجاز:

**روش ۱: Secret در URL**

URL را به این شکل تنظیم کنید:
```
https://your-domain.com/webhook.php?secret=YOUR_SECRET
```

**روش ۲: IP Whitelist**

در پنل تلفنچی، IP سرور خود را whitelist کنید.

## 18. عیب‌یابی

### مشکل: صفحه سفید

**راه‌حل**:
۱. در `config.php`:
   ```php
   define('DEBUG_MODE', true);
   ```
۲. صفحه را refresh کنید
۳. خطا را بررسی کنید
۴. پس از رفع، `DEBUG_MODE` را `false` کنید

### مشکل: خطای اتصال دیتابیس

**راه‌حل**:
- فایل `config.php` را بررسی کنید
- مقادیر `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS` را تصحیح کنید

### مشکل: تلفنچی کار نمی‌کند

**راه‌حل**:
- به صفحه تنظیمات بروید
- `service_id` و `token` را بررسی کنید
- روی «🧪 تست اتصال» کلیک کنید
- فایل `logs/error.log` را بررسی کنید

### مشکل: چت real-time کار نمی‌کند

**راه‌حل**:
- در `php.ini`:
  ```ini
  max_execution_time = 60
  output_buffering = Off
  ```
- در nginx (اگر استفاده می‌کنید):
  ```nginx
  fastcgi_read_timeout 60;
  proxy_buffering off;
  ```

### مشکل: فایل صوتی پخش نمی‌شود

**راه‌حل**:
- در DevTools → Network، درخواست `/api/play-recording` را بررسی کنید
- مطمئن شوید توکن در localStorage ذخیره شده
- فایل `logs/error.log` را بررسی کنید

### مشکل: کانبان drag & drop کار نمی‌کند

**راه‌حل**:
- مرورگر را به‌روز کنید
- در DevTools → Console، خطاهای JS را بررسی کنید

### مشاهده لاگ‌ها

```bash
tail -f logs/error.log
```

### پشتیبان‌گیری

```bash
mysqldump -u user -p jakojast > backup_$(date +%Y%m%d).sql
```

### بازیابی

```bash
mysql -u user -p jakojast < backup_YYYYMMDD.sql
```
